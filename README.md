# Happy Birthday, Ayah
Website ucapan ulang tahun sesuai referensi gambar.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder ini di VS Code.
3. Jalankan `index.html` dengan Live Server.

## Struktur
- `index.html` — struktur halaman
- `styles.css` — tampilan responsif
- `app.js` — tombol galeri dan interaksi
- `image/` — foto yang dipakai di halaman
